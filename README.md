# 📌 Задание 1 — Задача на алгоритмы


## Описание

Данное Node.js приложение выполняет обход файловой системы, анализирует структуру директорий и формирует список конечных папок, содержащих JavaScript-файлы.

Обход реализован с использованием алгоритма **DFS** через стек.


## Требования

Перед запуском убедитесь, что установлено:

- Node.js ≥ 18
- npm


## Установка зависимостей и запуск проекта

Перейдите в папку проекта `task1` в терминале и выполните:

```bash
npm install
npm run start
```


# 📌 Задание 2 — Автотест Wildberries (Playwright)


## Что делает тест

1. Открывает Wildberries
2. Вводит “транспортир” в поиск
3. Нажимает Enter
4. Сортирует по цене (возрастание)
5. Ждёт обновления списка
6. Забирает первые 10 товаров
7. Выводит в консоль:
    * название
    * цену
8. Делает скриншот результата


## Требования

Перед запуском убедитесь, что установлено:

- Node.js ≥ 18
- npm
- Google Chrome


## Установка зависимостей и запуск проекта

Перейдите в папку проекта `task2` в терминале и выполните:

```bash
npm install
npx playwright test
```
